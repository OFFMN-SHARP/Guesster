# 🧠 Guesster

### 给 AI 一把扳手，它能成为你的得力助手
Guesster 是一个极简的 AI 编程助手。它只做一件事，但做到极致：

> **你说话，AI 写 C# 代码，Guesster 执行它。**

你可以让它计算斐波那契数列、读取文件、甚至弹出 WinForms 窗口——所有这一切，都通过一个叫 `il_run` 的工具完成。
## ❓ 为什么是 Guesster？

传统的 AI Agent 动辄十几个工具（读文件、写文件、搜索、发邮件...），工具越多，攻击面越大，AI 也越容易选错工具。

Guesster 反其道而行之：**只给 AI 一个工具 `il_run`**。

- ✅ 攻击面从几十个骤降为 1 个
- ✅ AI 的选择困难症被彻底根治
- ✅ C# 的 BCL 就是你的工具箱，无限扩展
- ✅ 30KB 核心引擎，零依赖，单文件发布

## ✨ 核心特性

- **🧠 对话式编程**：用自然语言描述需求，AI 自动生成 C# 代码
- **🔧 单一工具设计**：只有 `il_run`，没有花里胡哨的插件
- **🎯 模型自主选择**：启动时动态探测并交互式选择可用模型
- **🛡️ 执行确认机制**：每次运行代码前都需要用户确认（方向键选择）
- **🔄 错误自愈**：AI 执行出错后会自动重试（最多 3 次）
- **🖥️ WinForms 原生支持**：AI 可以创建桌面应用程序
- **⚡ 5 秒超时保护**：防止死循环，永远不卡死
- **📦 零依赖单文件**：30KB 核心，即下即用
